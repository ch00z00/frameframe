    <p class="p-fact scene-fact reveal"><span class="ptype">事実</span>タイトルが出る前に、映画はすでに一つの謎を提示している。波打ち際に打ち上げられた老人が、見知らぬ子供たちに銃を向けられ、朽ちかけた要塞へ連れて行かれる。出迎えるのは、これも老いた斎藤。二人は初対面のように、しかしどこか旧知のように向き合う。観客はまだ何も説明されていない——これがいつの場面で、現実なのか、それとも別の何かなのか。</p>
    <div class="p-crit scene-crit reveal"><p><span class="ptype">批評</span>クリストファー・ノーランは、この映画を理解する手がかりになるはずの説明を、あえて最初に与えない。『インセプション』は、現実から始まり、夢の第1階層、第2階層、第3階層、そしてリンボへと潜っていく、五層の入れ子構造を持つ。この先、五つの階層はそれぞれ独立した場面として上から下へ普通に流れていく——画面中央に浮かぶ入れ子矩形の地図だけが位置を動かさず、いま読んでいる階層の輪を光らせて現在地を教え続ける。</p></div>
    <p class="p-fact scene-fact reveal"><span class="ptype">事実</span>出発点はコブの独楽(コマ)。彼が「現実」を確かめるために回し続ける、亡き妻から受け継いだ小さな道具である。この装置が最終的に何を意味するのかは、階層を降りきったところで扱う。</p>

    <p class="p-fact scene-fact reveal"><span class="ptype">事実</span>劇中の設定によれば、現実の10時間は第1階層の夢でおよそ1週間に相当する。物語の終盤、4つの階層(バンの車内、ホテル、雪山要塞、リンボ)で同時に進行する危機は、体感時間の速度がまったく異なるまま並行して編集される。バンが橋から落下する数秒が、上の階層では数分に、その下では数時間に、さらに下では数年に引き延ばされていく。</p>
    <div class="p-crit scene-crit reveal"><p><span class="ptype">批評</span>この換算比は、単なる添え物のガジェットではない。この設定が問うているのは、SF的などんでん返しではない。「どの階層の時間感覚を信じるか」という選択そのものが、映画全体の主題と重なっている。階層が深くなるほど、そこで過ごした時間は当人にとって長く、重く、現実味を帯びていく——コブがリンボで数十年分の記憶を積み重ねたように。ならば、どの階層が「本当の現実」かという問いは、経過時間の長さでは決められない。むしろ本作は、時間の相対性を突きつけることで、その問い自体を無効化しようとしている。</p></div>
    <p class="p-fact scene-fact reveal"><span class="ptype">事実</span>各階層への「キック(蹴り落とし)」の合図に使われるのは、エディット・ピアフの「水に流して」——それを引き伸ばして作られたハンス・ジマーの劇伴が、階層が一段深まるごとに、さらに引き伸ばされて鳴る。</p>
    <div class="p-crit scene-crit reveal"><p><span class="ptype">批評</span>この主題は音響にも刻まれている。観客が耳で聴いている音の速度そのものが、いま自分がどの深さにいるかを教えてくれる仕掛けだ。時間の相対性は、脚本上の設定であると同時に、スクリーンの外側、音の設計にまで及んでいる。</p></div>

<script>{`
  (function(){
    /* ---------------- reveal-on-scroll ---------------- */
    var revealTargets = Array.prototype.slice.call(document.querySelectorAll('.reveal'));
    if ('IntersectionObserver' in window){
      var ioReveal = new IntersectionObserver(function(entries){
        entries.forEach(function(entry){
          if (entry.isIntersecting){ entry.target.classList.add('is-revealed'); ioReveal.unobserve(entry.target); }
        });
      }, { rootMargin: '0px 0px -6% 0px', threshold: .04 });
      revealTargets.forEach(function(t){ ioReveal.observe(t); });
    } else {
      revealTargets.forEach(function(t){ t.classList.add('is-revealed'); });
    }

    /* ---------------- depth map tracking ---------------- */
    (function(){
      var depthMapAnchor = document.querySelector('.depth-map-anchor');
      var articleHero = document.querySelector('.article-hero');
      if (depthMapAnchor && articleHero){
        var syncDepthMapVisibility = function(){
          depthMapAnchor.classList.toggle('is-visible', articleHero.getBoundingClientRect().bottom <= 0);
        };
        syncDepthMapVisibility();
        window.addEventListener('scroll', syncDepthMapVisibility, { passive: true });
      } else if (depthMapAnchor) {
        depthMapAnchor.classList.add('is-visible');
      }

      var depthMeta = [
        { name: '現実' },
        { name: '夢・雨に沈む街' },
        { name: '夢・無重力のホテル' },
        { name: '夢・雪山要塞' },
        { name: 'リンボ' }
      ];
      var mapFrames = document.querySelectorAll('.depth-map .frame');
      var numEl = document.getElementById('depthMapNum');
      var nameEl = document.getElementById('depthMapName');
      function setActiveDepth(n){
        mapFrames.forEach(function(f){
          f.classList.toggle('is-current', f.getAttribute('data-depth') === String(n));
        });
        if (numEl && nameEl && depthMeta[n]){
          numEl.textContent = '0' + n;
          nameEl.textContent = depthMeta[n].name;
        }
      }
      var depthSections = Array.prototype.slice.call(document.querySelectorAll('.depth-section'));
      if (!depthSections.length) return;
      function resolveByPosition(){
        var triggerY = window.innerHeight / 3;
        for (var i = 0; i < depthSections.length; i++){
          var rect = depthSections[i].getBoundingClientRect();
          if (rect.top <= triggerY && rect.bottom >= triggerY){
            return Number(depthSections[i].getAttribute('data-depth'));
          }
        }
        var firstRect = depthSections[0].getBoundingClientRect();
        if (firstRect.top > triggerY) return 0;
        return Number(depthSections[depthSections.length - 1].getAttribute('data-depth'));
      }
      if ('IntersectionObserver' in window){
        var currentlyIn = {};
        var ioDepth = new IntersectionObserver(function(entries){
          entries.forEach(function(entry){
            currentlyIn[entry.target.getAttribute('data-depth')] = entry.isIntersecting;
          });
          var maxDepth = null;
          Object.keys(currentlyIn).forEach(function(k){
            if (currentlyIn[k] && (maxDepth === null || Number(k) > maxDepth)) maxDepth = Number(k);
          });
          setActiveDepth(maxDepth !== null ? maxDepth : resolveByPosition());
        }, { rootMargin: '-33% 0px -66% 0px', threshold: 0 });
        depthSections.forEach(function(s){ ioDepth.observe(s); });
      }
      setActiveDepth(0);
    })();
  })();
`}</script>
